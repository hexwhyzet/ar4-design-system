# Segmented

Выбор одного значения из 2–6 видимых вариантов: шаг джога, камера, захват, фильтр лога.

- **Передаёте:** `options` (строки/числа или `{value, label, disabled}`), `value`/`onChange` или `defaultValue`, `label`, `hideLabel`, `mono` — для числовых вариантов.
- Выбранный вариант — `accent-soft` с обводкой `accent`; разница видна и без цвета.
- Больше шести вариантов — `Select`.

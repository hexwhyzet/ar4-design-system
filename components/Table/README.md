# Table

Таблица параметров осей с редактируемыми ячейками.

- **Передаёте:** `columns` — `{key, label, align ('num' | 'center' | 'end'), width, hint}`; `rows` — объекты с узлами по ключам колонок.
- Кладите в `Panel flush`; подвал — `SaveBar`.
- `hint` превращает заголовок в подсказку с пунктирным подчёркиванием — для терминов вроде «Смещение», «Концевик».
- Числовые колонки выравниваются вправо и моноширинные.

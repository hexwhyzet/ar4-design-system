# CameraView

Поле видео с камерами: переключатель камер, индикатор потока и «На весь экран» поверх кадра.

- **Передаёте:** `src` (URL MJPEG/кадра; нет — состояние «Нет сигнала»), `cameras` (подписи), `camera`/`onCameraChange` или `defaultCamera`, `meta` (например «1280×720 · 30 fps»), `onFullscreen`, `emptyText`, `emptyDetail`.
- Поле всегда тёмное (`video`) в обеих темах; контролы поверх — с тенью `shadow-overlay`.
- Пропорции 16:10, ширина — по колонке. Не оставляйте пустое чёрное поле без подписи.

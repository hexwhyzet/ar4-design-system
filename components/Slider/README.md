# Slider

Непрерывная величина с текущим значением справа: скорость, раскрытие захвата.

- **Передаёте:** `label`, `value`/`onChange` или `defaultValue`, `min`, `max`, `step`, `unit`, `format`, `disabled`, `unknown` — значение не получено (показывается «—»).
- Значение справа всегда видно и моноширинное — оператор не должен угадывать по положению бегунка.

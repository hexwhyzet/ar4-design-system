# RangeBar

Шкала оси: допустимый диапазон между лимитами и текущее положение.

- **Передаёте:** `min`, `max` (лимиты, °), `value` (текущий угол, может отсутствовать), `domain` — полный механический диапазон, если лимиты уже него (на странице Оси — `[-180, 180]`), `ticks={false}` — без подписей.
- Метка положения — `accent`; в пределах 5% от лимита — `warn`. Нулевое положение — тонкая риска.
- Нет значения (нет связи, не откалибровано) — полоса пунктиром, метки нет. Не рисуйте метку в нуле «по умолчанию».

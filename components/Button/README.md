# Button

Кнопка действия.

- **Передаёте:** `variant` (`primary` | `secondary` | `ghost` | `danger` | `danger-outline`), `size` (`sm` | `md` | `lg`), `icon` (имя из `Icon`), `iconOnly` + `aria-label`, `disabled`, обработчики.
- Один `primary` на панель — главное действие (Сохранить, Запустить, Подключить).
- Кнопки джога −/+ — `secondary size="lg"` (48px), чтобы попадать пальцем.
- `disabled` рисуется пунктирной рамкой — заметно отличается от доступной кнопки и не теряет подпись.
- Текст — глагол в инфинитиве или короткое существительное: «Сохранить», «Калибровать».

# Notice

Сообщение о состоянии, которое меняет то, что можно делать на странице.

- **Передаёте:** `tone` (`danger` | `warn` | `ok` | `info`), `title` (короткое утверждение), `children` (последствие), `action` (одна кнопка), `bar` — растянуть на всю ширину под шапкой.
- Отсутствие связи с Teensy — один `Notice tone="danger" bar` в `Shell.banner`, с кнопкой «Подключить».
- Заголовок — что случилось, текст — что из этого следует. Без восклицательных знаков.

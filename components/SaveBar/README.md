# SaveBar

Подвал панели с редактируемой конфигурацией: состояние сохранения и кнопки «Отменить» / «Сохранить».

- **Передаёте:** `dirty` (число изменённых полей или `true`), `file` (по умолчанию `ARconfig.json`), `note`, `onCancel`, `onSave`.
- Кладётся в `Panel footer`. При изменениях подвал подсвечивается `warn-soft`, а изменённые поля — `Input dirty`.
- Когда изменений нет, обе кнопки неактивны, а слева — «Сохранено».

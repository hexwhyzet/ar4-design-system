# AppHeader

Верхняя полоса окна: имя приложения, вкладки страниц, статусы оборудования и СТОП справа.

- **Передаёте:** `title`, `subtitle` (версия), `nav` — `NavTabs`, `statuses` — массив пропсов `StatusChip`, `actions` — узлы справа.
- Слева направо: имя → вкладки → статусы (прижаты вправо) → действия.
- Порядок статусов фиксирован: Сервер → Teensy → Nano → калибровка. Отсутствующее обязательное устройство — `danger`, требование действия — `warn`.
- В `actions` всегда последним стоит `EStop`. Когда Teensy подключена — перед ним `Button variant="ghost"` «Отключить». Когда нет — кнопка «Подключить» живёт в баннере `Notice bar` под шапкой, а не здесь, чтобы не было двух одинаковых кнопок.
- Не дублируйте статус подключения отдельной плашкой-кнопкой справа (как было «Teensy не подключена») — это делает чип.

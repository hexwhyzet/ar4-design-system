# StatusChip

Короткий статус: метка формы + слово. Цвет никогда не работает один.

- **Передаёте:** `tone` (`ok` | `warn` | `danger` | `idle`), `label` (жирное), `detail` (уточнение).
- Форма метки дублирует цвет: `ok` — круг, `warn` — треугольник, `danger` — квадрат, `idle` — пустое кольцо.
- `ok` — голубой (`ok`), не зелёный: пара ok/danger различима при протанопии и дейтеранопии.
- Пишите состояние, а не отрицание: «Teensy · нет связи», а не «Teensy нет».

# Shell

Каркас окна: `AppHeader` с вкладками сверху, баннер под шапкой и прокручиваемая область страницы на всю ширину.

- **Передаёте:** `header`, необязательный `banner` (обычно `Notice bar`), `children` — содержимое страницы.
- Страница начинается с `PageHead` (`title`, `subtitle`, `actions`), затем панели с зазором `space-4`.
- Баннер «Teensy не подключена» живёт здесь, а не в каждой панели.

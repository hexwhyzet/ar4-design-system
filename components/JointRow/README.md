# JointRow

Строка джога одной оси: имя, текущий угол, шкала лимитов, кнопки − / +.

- **Передаёте:** `joint` (J1…J9), `value` (°), `min`, `max`, `step` (для `aria-label`), `onStep(dir)` где `dir` = −1 | 1, `disabled`, `digits`.
- Кнопка в сторону упёршегося лимита гаснет сама. Без связи или при активном `EStop` — `disabled` у всей строки.
- Шаг задаётся один на все оси через `Segmented` «Шаг» — не дублируйте его в каждой строке.

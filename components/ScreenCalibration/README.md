# ScreenCalibration

Страница «Калибровка»: автокалибровка, таблица осей, опасная зона «Наладка».

- «Автокалибровка» показывает стадии (`Stages`) и состояние, кнопки «Запустить» / «Прервать» — в шапке панели.
- «Оси» — `Table` в `Panel flush` с `SaveBar` в подвале. Две колонки-чекбокса «Стадия 1/2» заменены одним `Segmented` 1 | 2 — ось не может быть в обеих.
- «Направление» — словами (Прямое / Обратное), а не 1 / 0.
- «Наладка» — `Panel tone="danger"` последней на странице, кнопки `danger-outline` с позой в скобках моноширинным.

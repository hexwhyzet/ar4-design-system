# Readout

Плитка показания: подпись, крупное моноширинное число, единица. `Readouts` — сетка по три.

- **Передаёте:** `label`, `value` (число или строка; пусто → «—»), `unit`, `digits` (по умолчанию 2), `size="sm"`.
- Позиция инструмента — две строки: X Y Z (мм), затем Rz Ry Rx (°).
- Только для чтения. Если значение можно ввести — это `Input`.

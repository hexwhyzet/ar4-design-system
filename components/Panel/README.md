# Panel

Контейнер группы на странице: заголовок, необязательные мета и действия, тело, подвал.

- **Передаёте:** `title`, `meta` (счётчик или пояснение справа от заголовка), `actions` (кнопки в шапке), `footer` (обычно `SaveBar`), `flush` — тело без отступов (для `Table`, `LogView`), `tone="danger"` — опасная зона.
- Заголовок обычным регистром стилем `title`, без капса и разрядки.
- Панели не вкладываются друг в друга и не имеют теней — только граница `line` и `radius-lg`.
- `tone="danger"` — только для действий, которые ломают привязку координат («Наладка»). Кнопки внутри — `danger-outline`.

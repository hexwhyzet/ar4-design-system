# Input

Числовое поле с единицей измерения.

- **Передаёте:** `value`/`onChange` (или `defaultValue`), `suffix` (°, мм, %), `label`, `width`, `size="sm"` в таблицах, `dirty` — значение отличается от сохранённого, `invalid` — вне механического диапазона.
- Цифры моноширинные (`code`), отрицательные — с настоящим минусом «−».
- Единица — в `suffix`, не в подписи колонки, если колонка не однородна.

# EStop

Программный аварийный стоп: немедленно останавливает все оси. Добавлен намеренно — в старом интерфейсе остановки не было.

- **Передаёте:** `engaged` (стоп активен), `onClick`, `size="lg"` для сенсорного экрана.
- Всегда виден в `AppHeader`, на всех страницах, справа. Горячая клавиша — Пробел.
- В состоянии `engaged` кнопка становится «СБРОС СТОПА», а все кнопки движения — `disabled`.
- Не заменяет аппаратную кнопку аварийного останова и не используется для обычной остановки программы.

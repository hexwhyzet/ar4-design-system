# NavTabs

Вкладки страниц в шапке: Пульт, Калибровка, Оси, Лог — порядок и состав не меняются.

- **Передаёте:** `items` (`id`, `label`, необязательные `warn`, `count`, `key`), `value`/`onChange` или `defaultValue`. Кладётся в `AppHeader nav`.
- Активная вкладка — текст `ink` 600 и подчёркивание 2px `accent` по нижнему краю шапки. Остальные — `ink-muted`, при наведении подчёркивание `line-control`.
- `warn` — жёлтый треугольник у вкладки, пока там есть что сделать (Калибровка, пока робот не откалиброван); строкой передайте пояснение для скринридера. `count` — новые строки лога.
- Клавиши 1–4 переключают вкладки.

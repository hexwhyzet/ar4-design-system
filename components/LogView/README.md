# LogView

Лента событий сервера и обмена с контроллерами.

- **Передаёте:** `lines` — `{t, level, text}`, `level` = `info` | `ok` | `warn` | `error` | `tx` | `rx`; `height`; `emptyText`.
- Уровень — текстовой меткой (INFO, WARN, ERR), строка ошибки дополнительно подсвечена `danger-soft`.
- Команды на контроллер (`tx`/`rx`) приглушены — они нужны для отладки, а не для оператора.

# ScreenAxes

Страница «Оси»: программные лимиты J1–J6.

- Одна `Panel flush` с пояснением, `Table` и `SaveBar` с пометкой, что лимиты уходят в Teensy.
- Колонка «Диапазон» — `RangeBar` с общим `domain` −180…180°: лимиты разных осей сравнимы на глаз, видно текущее положение.
- Изменённые поля — `Input dirty`; подвал подсвечивается до сохранения.

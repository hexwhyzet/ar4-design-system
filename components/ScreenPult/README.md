# ScreenPult

Страница «Пульт»: камера, позиция и джог осей, захват.

- Две колонки: слева `Panel` «Камера» (`CameraView`) и под ней «Захват»; справа — «Позиция и управление» шириной 560px.
- В «Позиции»: шесть `JointRow`, затем `Readouts` (X Y Z / Rz Ry Rx), затем «Шаг» (`Segmented mono`) и «Скорость» (`Slider`) — общие для всех осей.
- Камеры переключаются поверх кадра, а не кнопками под ним.
- Без связи: баннер в `Shell`, все `JointRow disabled`, показания «—».
